# ⚔️ Element Chess TD

Auto-Chess × Tower Defense multiplayer browser game.

Combine elemental towers, manage your economy, and hex your opponents.

## Quick Start

```bash
npm install
npm run dev
```

- Client: http://localhost:5173
- Server: ws://localhost:3001

## LAN Play

```bash
npm run build && npm start
# Share your local IP with friends
```

## Stack

- **Client:** Phaser 3 + TypeScript + Vite
- **Server:** Node.js + WebSocket
- **Shared:** TypeScript types & game constants
